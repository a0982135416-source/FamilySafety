## 4. Safety 核心規則

以下為正式規格，並非宣稱現有 Mock UI 全部已接入正式安全判斷：

- GAS_LEAK_RISK：Gas ON + Flame NOT detected → immediate alert，不依賴安全倒數。
- Unattended cooking：Flame detected + Person NOT detected → auto-start countdown；Gas ON 不作為 countdown 必要條件。
- Person returns → cancel/reset countdown。
- Countdown expires 且 Person 仍未偵測 → UNATTENDED_COOKING；不額外要求 Gas ON 或 Flame detected。
- Countdown default：10 minutes；使用者可自由輸入整數分鐘數，不採固定 5 / 10 / 15 / 30 選項。
- Temperature / Humidity：monitoring only，不產生 alert。
- Mock Resolve 不代表 Server 已驗證現場安全；正式危險條件由 Server 判斷。
